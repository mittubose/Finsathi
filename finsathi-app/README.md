# FinSathi Web Application

The core client interface and unified local daemon for the FinSathi Financial Operating System.

## Quick Start

```bash
# Install dependencies
npm install

# Start Vite client development server
npm run dev

# Start Unified MCP Daemon & Local Server (port 3001)
node server/mcp-server.mjs

# Build for production
npm run build
```

For full installation instructions across devices (macOS, Windows, Linux, iOS PWA, Android PWA) and companion setups, see the main [README.md](../README.md).
